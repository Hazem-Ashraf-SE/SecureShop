Attacks and Vulnerabilities:
----------------------------

**Practical Lab Exploits**

* Excessive Trust in Client-Side Controls (Price Tampering)
* Flawed Enforcement of Business Rules (Coupon Stacking)
* Inconsistent Handling of Exceptional Input (Email Truncation & Privilege Escalation)
* Insufficient Workflow Validation (Checkout/Payment Bypass)
* 2FA Broken Logic (Cookie Hijacking & OTP Brute-Force)

**Defensive Lab Threats & Attacks**

* Account Takeover (ATO)
* Automated Bot / Credential Pasting
* Imposter / Unfamiliar Typing
* Behavioral Profile Poisoning
* Sensitive Keystroke Data Exposure
* Password Phishing
* Remote / Out-of-Region Logins
* Off-Hours Access
* Coordinate / GPS Spoofing
* OTP Code Capture / Replay
* Cryptographic Signature Tampering & Credential Mismatch

**Business Logic Vulnerabilities**

* Excessive trust in client-side controls
* High-level logic vulnerability
* Inconsistent security controls
* Flawed enforcement of business rules
* Low-level logic flaw
* Inconsistent handling of exceptional input
* Weak isolation on a dual-use endpoint
* Insufficient workflow validation
* Authentication bypass via flawed state machine
* Infinite money logic flaw
* Authentication bypass via encryption oracle

**General Web Attacks & Recon**

* Data Leaks
* Input Validation Bypass
